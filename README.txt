Локальный сервер Codex для TestRail AI Generator

Репозиторий проекта не нужен. Распакуйте весь архив в отдельную папку.

Один раз установите Node.js 22.12 или новее: https://nodejs.org/

Windows x64:
Откройте Start Windows.cmd двойным щелчком. Codex CLI уже находится в папке
codex и запускается напрямую: установка через npm не требуется. При необходимости
откроется вход в Codex через браузер. Оставьте окно сервера открытым.
Используйте Start Windows.cmd для запуска сервера.

macOS / Linux:
Один раз установите Codex CLI: npm install -g @openai/codex
Официальная инструкция: https://developers.openai.com/codex/cli/
Откройте терминал в распакованной папке и выполните:
  codex login
  node codex-bridge.mjs
Оставьте терминал открытым. Для остановки нажмите Ctrl+C.

Подключение расширения:
1. В настройках выберите Codex (локальный сервер).
2. Нажмите «Подключить Codex».
3. В Windows подтвердите подключение кнопкой «Да» в отдельном окне TestRail AI Generator. В других системах введите y в окне сервера и нажмите Enter.
   Адрес и доступ сохранятся автоматически. Вручную ничего копировать не нужно.
4. Модель можно оставить пустой: используется стандартная модель Codex.
   Личный config.toml не загружается; авторизация Codex сохраняется.
   Сохраните настройки расширения.

Подключение подтверждается один раз. При обычном перезапуске сервера повторять
его не нужно. Подтверждайте только запрос, который вы сами начали в расширении.
Служебный ключ доступа хранится вне архива: в Windows —
%LOCALAPPDATA%\TestRail-AI-Generator\.codex-bridge\token.
Старый ключ из .codex-bridge/token рядом со скриптом переносится при первом
запуске обновлённого сервера. Подключение сохраняется между обновлениями.

Запускайте сервер каждый раз, когда хотите использовать этот режим.
Node.js не входит в архив. Codex CLI для Windows x64 входит в архив.
Сервер не требует npm install в своей
папке и не использует файлы репозитория. Интернет нужен для работы Codex.

Чат:
Для работы из чата рекомендуем самостоятельный плагин testrail-chat-plugin.zip.
Сервер входит в плагин и запускается при подключении MCP: скачивать этот
серверный архив и запускать Start Windows.cmd для чата не требуется.
Установите Node.js 22.12+, распакуйте плагин, один раз запустите его
Install Windows.cmd и выберите TestRail AI Generator в новой беседе.
При первом подключении расширения подтвердите системный диалог.

Ниже описан альтернативный вариант подключения через этот серверный архив.
Один запущенный сервер одновременно обслуживает генерацию из расширения
и команды из чата. Переключать режим и запускать второй Codex не нужно.

В Windows x64 один раз запустите Connect Chat Windows.cmd из архива.
Он зарегистрирует инструменты в локальных настройках Codex. После этого
перезапустите MCP-подключение / откройте новую беседу.

Для ручной настройки добавьте MCP-сервер в настольном клиенте
ChatGPT / Codex: Настройки → MCP servers → Add server → STDIO.
Команда: node
Аргумент: полный путь к testrail-chat/server.mjs в распакованной папке.
Например: C:\TestRail-Codex\testrail-chat\server.mjs
После сохранения перезапустите MCP-подключение / откройте новую беседу,
чтобы клиент загрузил инструменты сервера.

Либо добавьте через установленный Codex CLI:
  codex mcp add testrail-extension -- node "C:\TestRail-Codex\testrail-chat\server.mjs"
Замените путь на свой. Встроенный codex\codex-x86_64-pc-windows-msvc.exe
тоже поддерживает эту команду. Этот шаг выполняется один раз.

Адаптер использует общую папку данных TestRail AI Generator и сам запускает
сервер, если он ещё не запущен. Копировать токен в настройки чата не нужно.
Для использования старой папки с .codex-bridge/token можно задать
CODEX_BRIDGE_DIR равным этой папке.
Нестандартный порт задаётся через CODEX_BRIDGE_PORT и для сервера, и для адаптера.

Держите панель расширения открытой. Попросите чат прочитать её состояние,
создать кейсы или изменить черновики в разделе «Генерация ТК».
При нескольких открытых панелях чат увидит отдельные sessionId.
Изменения появятся в расширении автоматически. Генерация из расширения
при этом остаётся доступной. Во время активной задачи панель отклоняет
изменения из чата; чтение состояния продолжает работать.

Перед созданием или переработкой кейсов чат получает актуальный промпт
из редактора расширения через get_extension_prompt: для создания — generate,
для редактирования — edit. Можно назвать вариант промпта; по умолчанию
используется первый, как на основной кнопке расширения. Варианты промптов
не объединяются. Если выбранный промпт пуст, сначала заполните его в расширении.

Чат получает текст задачи, инструкции и черновики. API-ключи, пароли TestRail
и токен сервера в инструменты не передаются. Инструменты чата не выгружают
кейсы в TestRail и не меняют уже выгруженные кейсы.

Спека:
В обновлённом расширении вкладка «Спека» позволяет получить загруженный текст
веб-страницы и создать спецификацию в Markdown. Используется тот же сервер;
для запуска из расширения передаётся task: specification. Исходные материалы
и документ можно редактировать и копировать. Публикации в Confluence нет.
В чате получите промпт с purpose: specification и исходный текст из
specification.source через get_extension_state. Готовый Markdown передайте
через set_specification — он появится во вкладке и сохранится локально.
Вместо PDF текст страницы передаётся напрямую; PDF-просмотрщики не извлекаются.

Обычный веб-чат сам по себе не получает доступ к localhost: описанное
подключение предназначено для клиента с поддержкой локальных MCP-серверов.
