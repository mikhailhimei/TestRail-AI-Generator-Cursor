Пояснение о чтении исходников перенесено из текста под списком в подсказку со значком «!» рядом с названием поля. Подсказка использует общий компонент HelpTooltip, доступна при наведении и фокусе.

Расширение Chrome 1.1.6. Сохранены выпадающий список разрешения, исправление генерации JSON-моков, поддержка Codex/Gemini/Copilot и 7 MCP-инструментов. Сборки web и extension прошли.

Для Linux-приложения обновите ветку feat/docker-local-server, выполните npm run build:web и перезапустите systemctl --user restart testrail-ai-generator, затем обновите страницу.
