Исправлена установка CLI на медленном соединении: прежний лимит curl 900 секунд обрывал загрузку большого Codex для Windows.

- До 3600 секунд на попытку, 3 попытки с докачкой. Зависшее соединение без приемлемой скорости прерывается через 120 секунд.
- Частичные архивы сохраняются между запусками установщика в системной временной папке testrail-cli-downloads; повторный запуск продолжает загрузку того же пакета.
- Перед установкой сверяется SHA-512 из метаданных npm. Повреждённый завершённый архив не устанавливается; проверенный архив используется повторно.
- Если сервер/прокси не поддерживает Range или возвращает HTTP 416, загрузка безопасно начинается заново.
- Изменение общее для установщиков Codex, Gemini и Copilot. UI расширения не менялся: архив Chrome остаётся 1.1.7 из v1.5.5.

Скачайте свежий архив своего MCP-клиента и запустите Install Windows.cmd. Старый установщик удалял временную загрузку после ошибки; прерванные им 86 МБ восстановить нельзя.

Проверки: тесты имитируют Windows/curl, обрыв, докачку внутри попыток и после повторного запуска, проверенный кэш, повреждённый файл, неподдерживаемые Range/HTTP 416 и отклонение недоверенных метаданных. Все 8 тестов репозитория прошли. Реальная загрузка 188-МБ пакета на компьютере пользователя не выполнялась.
