В параметры генерации добавлен переключатель «Разрешить чтение исходников на сервере», выключенный по умолчанию. Без разрешения запрос с абсолютным путём к проекту останавливается, а shell-инструменты Codex отключаются.

Исправлен запуск генерации из поля «Требования»: сервер больше не запрещает Codex использовать инструменты чтения исходников. Режим read-only сохранён.

- Если в требованиях указан абсолютный путь к проекту вида /home/..., сервер проверяет существование и права чтения до запуска AI. Ошибка останавливает генерацию.
- Codex получает инструкцию сначала прочитать реализацию, модели и API, а при отсутствии доступа вернуть ошибку вместо придуманных кейсов. Ошибка AI показывается приложению.
- Та же инструкция передаётся Gemini и Copilot; доступ к внешним папкам дополнительно зависит от разрешений их CLI. Проверки с тестовыми процессами пройдены; реальное чтение пользовательского проекта каждым CLI не проверялось.
- JSON-моки и 7 MCP-инструментов из v1.5.0 сохранены. Расширение Chrome 1.1.3 содержит переключатель разрешения в параметрах генерации ТК, редактирования и спецификации. Он выключен по умолчанию. Требуется обновление расширения и серверного runtime.

Linux HTTP-сервер на порту 6252: обновите ветку feat/docker-local-server приложения и перезапустите systemctl --user restart testrail-ai-generator. Для него переустановка MCP-архива не требуется.

Проверены протокол MCP, генерация моков через три CLI-маршрута, остановка до запуска CLI при отсутствующем пути, чтение исходника вне временного cwd тестовым CLI и обработка ошибки анализа. Реальные аккаунты и папки пользователя в этой среде недоступны.
