# TestRail AI Generator для Codex, Gemini и Copilot

Локальный сервер связывает расширение Chrome TestRail AI Generator с Codex, Gemini CLI и GitHub Copilot. Чат может читать кейсы и промпты и редактировать черновики. Панель Chrome может запускать генерацию кейсов, спецификаций и автотестов через CLI выбранного агента.

## Установка для Codex

Скачайте архив своей системы со [страницы релизов](https://github.com/mikhailhimei/TestRail-AI-Generator-Cursor/releases). Клонировать репозиторий не нужно. Требуется Node.js 22.12 или новее.

| Система | Архив | Установщик |
| --- | --- | --- |
| Windows x64 | `testrail-chat-plugin.zip` | `Install Windows.cmd` |
| macOS | `testrail-chat-plugin-unix.zip` | `Install macOS.command` |
| Linux | `testrail-chat-plugin-unix.zip` | `sh "Install Linux.sh"` |

Распакуйте весь архив и запустите указанный установщик из папки `testrail-chat`. В Windows Codex CLI входит в архив. На macOS/Linux установщик использует системный Codex CLI и при отсутствии устанавливает его через npm. В Linux нужны графический сеанс и пакет `zenity` для окна подтверждения; в macOS используется штатный `osascript`.

Если macOS-архиватор не сохранил право запуска, выполните `sh "Install macOS.command"` в терминале распакованной папки.

После установки:

1. Создайте **новый чат Codex** с плагином **TestRail AI Generator**. Продолжение старой беседы может не загрузить только что установленный плагин.
2. Откройте панель расширения. В настройках выберите **Codex (локальный сервер)** и нажмите **Подключить Codex**.
3. Разрешите подключение в появившемся окне. В Windows нажмите **Да**.

Сервер запускается вместе с MCP-подключением плагина. Держите чат подключённым, а панель расширения открытой. Для генерации из расширения при необходимости один раз выполните вход в Codex: `codex login` (в Windows можно использовать встроенный CLI).

В чате можно попросить получить промпт BFF, создать тест-кейсы или подготовить спеку. Изменения сохраняются в черновиках расширения, без автоматической публикации в TestRail или Confluence. Подробности — [инструкция плагина](testrail-chat/README.md).

## Подключение Gemini CLI и GitHub Copilot

Скачайте `testrail-mcp.zip` и `testrail-chrome-extension.zip` из одного релиза. Нужен Node.js 22.12 или новее. Распакуйте оба архива. На странице `chrome://extensions` включите режим разработчика и загрузите папку Chrome-расширения, в которой находится `manifest.json`.

- **Gemini CLI.** Установите Gemini CLI, выполните вход и из терминала добавьте сервер командой `gemini mcp add --scope user testrail-extension node "/полный/путь/testrail-chat/server.mjs"`. Запустите `gemini` в доверенной папке. Команда `/mcp list` покажет подключение.
- **Copilot в VS Code.** Добавьте сервер в пользовательский `~/.copilot/mcp-config.json` или в `.mcp.json` проекта. В объекте `mcpServers` добавьте запись `"testrail-extension": { "type": "stdio", "command": "node", "args": ["/полный/путь/testrail-chat/server.mjs"] }`. Откройте чат Copilot и запустите сервер.
- **Панель Chrome.** Выберите **Gemini MCP** или **Copilot MCP**, нажмите «Подключить» и подтвердите доступ. Оставьте панель и MCP-подключение открытыми. Закройте старые сессии с сервером предыдущей версии, чтобы новый сервер мог занять локальный порт.

Для генерации из Chrome нужен авторизованный `gemini` или `copilot` в PATH процесса MCP. Copilot CLI устанавливается отдельно для запуска из Chrome. Для генерации АТ укажите корень Git-проекта и настройте в CLI разрешения на нужные команды проверок и браузерные инструменты. Gemini CLI должен доверять папке проекта.

## Исходники

Для клонирования исходников с Windows CLI нужен Git LFS:

```sh
git lfs install
git clone https://github.com/mikhailhimei/TestRail-AI-Generator-Cursor.git
cd TestRail-AI-Generator-Cursor
git lfs pull
```

Обычный GitHub Source code ZIP может содержать LFS-указатели вместо исполняемых файлов. Для установки используйте готовые архивы, приложенные к релизу.

## Данные и проверка

Ключ подключения создаётся локально; пользовательские токены и вход Codex в пакет не включаются. Обновление плагина сохраняет подключение. Сервер слушает только `127.0.0.1` и запрашивает подтверждение перед передачей ключа расширению.

Установщики проверены в POSIX shell с имитацией системных зависимостей; ZIP проверен на права выполнения и окончания строк LF. Проверка на реальных macOS/Linux пока не выполнена.
