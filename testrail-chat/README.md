# TestRail AI Generator — плагин для чата

Сервер входит в плагин и запускается при подключении MCP. Отдельно скачивать серверный архив и запускать `Start Windows.cmd` для чата не нужно.

## Установка

1. Установите Node.js 22.12 или новее, если он ещё не установлен.
2. Распакуйте архив и один раз запустите установщик своей системы:
   - Windows x64: `testrail-chat-plugin.zip` → `Install Windows.cmd`.
   - macOS: `testrail-chat-plugin-unix.zip` → `Install macOS.command` (двойной щелчок).
   - Linux: `testrail-chat-plugin-unix.zip` → `sh "Install Linux.sh"` в терминале распакованной папки.
3. Перезапустите MCP-подключение / откройте новую беседу и выберите **TestRail AI Generator**.
4. Откройте актуальную панель расширения. В её настройках нажмите **Подключить Codex**. Разрешите подключение в появившемся системном диалоге.

Установщики macOS/Linux проверяют Node.js и устанавливают официальный Codex CLI через npm, если он отсутствует. В Linux нужен графический сеанс и пакет `zenity` для подтверждения подключения. Установите его менеджером пакетов своей системы, если установщик попросит. В macOS используется штатный `osascript`. Если архиватор не сохранил право запуска macOS-файла, выполните `sh "Install macOS.command"` в терминале распакованной папки. Установщик не применяет `sudo` и не меняет настройки безопасности системы.

При обычной работе нужен только открытый новый чат с подключённым плагином и открытая панель расширения. Сервер работает в процессе MCP, пока подключение активно. Уже запущенный совместимый сервер используется повторно. Обычная генерация из расширения и команды чата доступны одновременно.

Примеры: «Покажи доступные промпты», «Создай кейсы по промпту BFF», «Подготовь спеку по материалам вкладки “Спека”». Чат получает актуальный промпт из расширения. Изменения появляются в черновиках; публикации в TestRail или Confluence инструменты не выполняют.

## Данные подключения

Токен создаётся у пользователя и не входит в пакет. Данные подключения сохраняются вне папки плагина: Windows — `%LOCALAPPDATA%\TestRail-AI-Generator\.codex-bridge`, macOS — `~/Library/Application Support/TestRail-AI-Generator/.codex-bridge`, Linux — `${XDG_STATE_HOME:-~/.local/state}/testrail-ai-generator/.codex-bridge`. Поэтому обновление плагина не сбрасывает подключение.

Для совместимости с прежним сервером можно задать `CODEX_BRIDGE_DIR` — папку, содержащую `.codex-bridge/token`; `CODEX_BRIDGE_PORT` задаёт порт (по умолчанию 3210). Если порт занят сервером с другим ключом, плагин сообщает ошибку и не обходит проверку доступа.

Windows-комплект также содержит Codex CLI для генерации из расширения. В macOS/Linux установщик использует системный Codex CLI, при отсутствии устанавливает его через npm. Для генерации из расширения при необходимости выполните `codex login` один раз. Для команд из чата отдельный CLI-сеанс и отдельный вход не запускаются. Подтверждение подключения использует системный диалог (`osascript` / `zenity`).

Ручная установка: `node install.mjs`. Обычный веб-чат без поддержки локальных MCP-процессов этот плагин не запускает.
